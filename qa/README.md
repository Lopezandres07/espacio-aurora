📄 QA Strategy & Automation - Espacio Aurora
Este directorio contiene la suite de pruebas automatizadas para asegurar la calidad y la integridad de los flujos críticos del SaaS de Espacio Aurora.

🎯 Objetivo
Garantizar que el proceso de captura de leads y agendamiento vía WhatsApp funcione sin fricciones, asegurando que cada clic se registre correctamente en la base de datos para análisis posterior.

👥 Historias de Usuario (HU)

📨 Whatsapp

- HU1: Como Usuario Invitado, quiero ingresar mi nombre al contactar por WhatsApp para que la especialista sepa quién soy desde el primer mensaje.
- HU2: Como Usuario Registrado, quiero que mi nombre aparezca autocompletado en el menú de contacto para agilizar mi proceso de reserva.

🔒 Flujo de Autenticación

Registro e Inicio de Sesión

- HU1: Como cliente nuevo, quiero crear una cuenta con mi correo y teléfono para llevar un registro de mis tratamientos y agendar más rápido.

⚙️ Flujo de Administración

Gestión de Agenda

- HU1: Como administradora, quiero ver un calendario con todas las citas del día para organizar mi tiempo y preparar los insumos necesarios (como el Pink Glow o las vitaminas).
- HU2: Como Administradora, quiero que cada intento de contacto quede registrado en el sistema para medir qué servicios son los más solicitados.
