# Project Context: Espacio Aurora (SaaS)

## Vision
Plataforma SaaS para estética y belleza enfocada en la conversión y gestión de citas.
Marca: Espacio Aurora (Estética "Soft Luxury").

## Tech Stack
- **Frontend:** React + TypeScript + Vite + Tailwind CSS.
- **Backend:** Node.js + Express + TypeScript + PostgreSQL.
- **QA:** Playwright + Cucumber (BDD) + Gherkin.

## Visual Identity
- **Primary:** #C299D1 (Soft Lilac)
- **Secondary:** #9370DB (Deep Lavender)
- **Background:** #F9F7FA (Aurora White)
- **Text:** #3D3D3D (Graphite)
